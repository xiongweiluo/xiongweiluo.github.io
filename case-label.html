01A workspace for teams building labelled datasets.

LabelHub helps data teams organise annotation work, produce consistent labels and review their quality in one place.

Task management

02Three roles. One connected workflow.

Each role gets a focused workspace, with a clear handoff to the next person.

Owner

Set up the work

Define the fields, publish the template and assign the task.

Annotator

Create the labels

Read the source, complete the form and submit an answer.

Reviewer

Check the quality

Check submissions, revise fields or return work for changes.

Task + template→ Submitted labels→ Reviewed resultRevisions return to the annotator

03Follow one news annotation from setup to review.

The same task connects the owner’s instructions, the annotator’s answer and the reviewer’s changes.

  1. News quality annotationOwner publishes the task
  2. Finance · quality score 2Annotator adds a fact-check note
  3. Quality score 2 → 1Reviewer prepares a visible revision
Annotator · source and answer
Reviewer · source and submitted fields
Reviewer · field-level change

04Define the rule once. Carry it through the task.

I designed the shared schema architecture so that a field means the same thing wherever it appears.

ONE RULE

A low score needs a reason.

The schema carries field identity, conditions and validation across the designer, working form and review.

Quality score 1 or 2↓Show Fact-check note↓Require an explanation before submission
Owner · schema designer
